# KitaBranding Component Library

The components of [karolina.kita.company](https://karolina.kita.company), the portfolio of Karolina Kita, Senior Product Designer. They come from KitaBranding, Karolina’s design system in Figma. Every story renders the site’s own code, with the same tokens and real copy from the pages.

## Built from Figma

- **Tokens first:** every colour, space, radius, shadow, type style and motion value is a variable in the Figma file, with values for Light and Dark mode. The variables are exported to JSON and turned into CSS variables, and a test fails when the code and the export drift apart.
- **Only tokens:** the default Tailwind colours, sizes and radii are switched off, so a component can only use values from the design system, such as `bg-bg-canvas`, `p-md` or `text-body-md`.
- **Names from Figma:** components and variants keep the names from the Figma Components page. `Button` has the Primary, Secondary, Subtle and Link types, and `Callout` has the Info and Warning tones of the Figma Banner.
- **Light and Dark mode:** Dark mode swaps the same variables, so no component has separate dark styles.

## In the Sidebar

- **Foundations:** the icon set.
- **UI:** the building blocks of every page: buttons, badges, cards, callouts, breadcrumbs, links, the dialog, the accordion and the page structure.
- **Layout:** the header with its navigation and theme switch, the footer and the back-to-top button.
- **Media:** case-study thumbnails and screenshots.
- **Patterns:** larger pieces made of several components, such as the statistics consent box.

## How to Use It

- **Theme:** the Theme menu in the toolbar switches between the Light and Dark mode tokens.
- **Docs:** each component has a Docs page with its props and all its stories.
- **Accessibility:** the Accessibility panel runs axe on the open story. In the test run every story renders, runs its interaction checks and must pass axe for WCAG 2.2 A and AA. Colour contrast is checked on the real pages, where the layout is complete.
